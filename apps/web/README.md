# Beefficient Web

MVP web dashboard for cattle grazing analysis and reporting.

## Setup

```bash
npm install
npm run dev
```

Visit http://localhost:3001

## Build

```bash
npm run build
npm start
```

## Project Structure

- `src/app/` — Next.js routes
- `src/components/` — Reusable React components
- `src/lib/` — Mock data, types, utilities
- `src/styles/` — CSS with design tokens
