# Tokens

Fuente: `packages/design-system/tokens/*.json`, tomados del prototipo
`Beefficient_29.7.26`. Style Dictionary genera:

| Salida | Uso |
|---|---|
| `@beefficient/tokens/native` | Objeto anidado para React Native: `tokens.color.accent.base`, números sin unidad. Lo usa `@beefficient/ui`. |
| `@beefficient/tokens` | Exports ES6 en camelCase: `colorAccentBase`. |
| `@beefficient/tokens/css` | Variables CSS: `var(--color-accent-base)`. |
| `@beefficient/tokens/json` | JSON plano en kebab-case. |

Algunos tokens no están en el prototipo y salen del wireframe: `tile`, `input`,
`text.error`, los radios `control` (12), `tile` (22) y `sheet` (24), y la serie de colores de
lote. Están marcados así en la descripción de cada token.
